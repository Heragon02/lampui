# Lamp UI (Fabric, Minecraft 1.21.11)

Ламповый интерфейс: процедурный вращающийся пейзаж (лес / снег / пустыня / озеро) с реальным временем суток,
тёплые стеклянные кнопки и слайдеры, спокойная музыка (день/ночь), экран загрузки с фонариком.

## Как получить jar без установки Java
1. Создайте пустой репозиторий на github.com и загрузите в него содержимое этой папки.
2. Вкладка **Actions** → workflow **build** → дождитесь зелёной галочки (2–4 минуты).
3. Внутри запуска, раздел **Artifacts** → `lampui-jar` → скачайте zip, внутри `lampui-0.1.0.jar`.
4. Положите jar и Fabric API (0.141.x для 1.21.11) в `.minecraft/mods`.

## Локальная сборка
Java 21 + Gradle 9.x: `gradle build` → `build/libs/lampui-0.1.0.jar`; `gradle runClient` — тестовый запуск.

## Настройки
Кнопка **Lamp UI** в левом верхнем углу главного меню; файл `config/lampui.json`.
Время для теста: `-Dlampui.hour=21.5`
